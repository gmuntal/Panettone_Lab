# Panettone Lab v0.15.0 — mode simple

## Canvis

- Afegeix una pantalla d’inici simplificada amb fotografia, temperatura disponible, temps, creixement validat, estat del registre i una acció principal.
- Guia l’inici en tres passos. Permet triar tipus, conservar un objectiu de temperatura com a dada de la fermentació, decidir si s’hi associen fotos i obrir camps addicionals.
- Permet afegir una nota i finalitzar la fermentació des de la pantalla principal.
- Afegeix navegació simple «Inici / Històric / Ajustos» i selector persistent de mode simple/avançat.
- Manté les pantalles i eines existents en mode avançat i conserva els temes v0.14.0.
- Mostra alarmes resumides i errors de sensor/càmera amb instruccions comprensibles.

## Compatibilitat i límits

La selecció del tipus queda registrada com una nota inicial perquè el model actual de dades no disposa d’un camp `type`; no es modifica l’esquema SQLite. El multiplicador de creixement només apareix quan la sèrie de l’API de creixement conté una mesura calibrada i vàlida. L’objectiu de temperatura només s’adjunta a la fermentació i no canvia el control tèrmic.

No es canvien endpoints, base de dades, procés de captura, dispositius ni lògica/proteccions tèrmiques. El mode és només una preferència d’interfície desada al navegador. No s’ha publicat a producció.
