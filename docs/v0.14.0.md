# Panettone Lab v0.14.0 — base visual i temes

## Canvis

- Afegeix els temes clar, fosc i automàtic segons la preferència del sistema.
- Desa la preferència al navegador d’aquest dispositiu i la sincronitza entre pestanyes.
- Aplica el tema abans de carregar els estils per evitar un flaix de tema incorrecte.
- Inclou la pantalla d’accés i el dashboard i incorpora els nous recursos a la memòria cau de la PWA.

## Abast i compatibilitat

És una fase visual. No canvia les API, autenticació, esquemes SQLite, dades, captures, sessions, temporitzadors ni lògica/proteccions del control tèrmic. La preferència de tema queda al navegador, no a SQLite.

El redisseny de les pantalles Inici, Històric i Ajustos, el mode simple/avançat i el flux curt d’inici de fermentació encara no formen part d’aquesta fase.
