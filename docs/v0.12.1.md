# Panettone Lab v0.12.1 — redisseny UX del dashboard

## Canvis

- El dashboard identifica separadament l’hora de consulta i l’antiguitat de l’última lectura vàlida.
- Manté visibles els últims valors vàlids quan un intent posterior falla i n’indica l’error; les dades antigues no es presenten com a actuals.
- L’estat de la càmera diferencia seguiment aturat, manca de captures, intent fallit, captura recent i captura antiga. Una fallada nova no esborra de la interfície la darrera fotografia vàlida.
- La gràfica indica les escales separades de temperatura (°C) i humitat (%), tolera sèries parcials/nul·les i té una taula textual accessible amb les mostres recents.
- La fotografia recent es presenta després de les mètriques i la tendència. En mòbil, les mètriques es mostren en una columna; controls i botons principals tenen objectius de 44 CSS px o més.
- Es puja la versió estàtica a v0.12.1 perquè el navegador i el service worker detectin CSS i JavaScript nous. El service worker continua excloent `/api/` i `/photos/` de la memòria cau.

## Límits i preservació

Aquest canvi només toca la presentació i el tractament dels estats al navegador. No modifica les rutes/API, autenticació, intervals, workers, dispositius, configuració del Shelly, codi d’accionament, esquema SQLite, fitxers de dades ni persistència. No s’ha introduït ni enviat cap ordre tèrmica. No s’ha fet cap desplegament.

## Comprovació

Les proves automatitzades de frontend i backend s’executen amb:

```sh
node --test tests/camera_state.test.js tests/probe-chart.test.js
python -m unittest discover -s tests -v
```

La comprovació automatitzada no substitueix una revisió visual als viewports 320×568, 375×667, 390×844, 768×1024 i 1280×800 CSS px, ni una prova física amb lector de pantalla. Aquestes comprovacions visuals requereixen servir la versió local amb sessió iniciada.
