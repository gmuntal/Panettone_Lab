# Panettone Lab v0.16.1

Correccions UX/UI prioritàries després del redisseny:

- El selector simple/avançat ara s'inicialitza i s'escolta des del mòdul de preferències, amb canvi immediat, persistència local i sincronització entre pestanyes.
- La capçalera mostra «Panettone Lab · v0.16.1» i «by gmuntal» sense afegir una segona capçalera.
- La navegació mòbil ocupa menys espai, conserva botons tàctils de 48 px i reserva l'àrea segura inferior una sola vegada.
- El servidor és l'única font de la versió; la genera als URL del manifest i del service worker perquè la PWA renovi els recursos en publicar.

La publicació no modifica el control tèrmic, les API de negoci, l'esquema SQLite, les fotografies ni les dades de fermentació.
