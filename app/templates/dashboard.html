    Mode d’ús

    El mode simple mostra només les accions i dades essencials. El mode avançat manté totes les eines.

    Canviar de mode no atura ni modifica cap procés.

    Aparença

    La preferència es desa en aquest navegador.

    Captura i sensors

    Lectures ambientals cada {{ sensor_interval_seconds }} s.

    Fotografies cada {{ photo_interval_seconds }} s quan el registre automàtic és actiu.

    Dispositius locals

    Shelly Plus UNI · temperatura i humitat ambientals.

    Tapo C210 · fotografies de la fermentadora.

    Els valors ambientals no són una mesura de la temperatura interna de la massa.

    Sonda de temperatura de massa

    El token de lectura es configura al servidor. La sonda complementa la lectura ambiental. Activa el registre automàtic per enregistrar dades.

    Control tèrmic

    La manta tèrmica és Shelly switch:0 segons confirmació de l’usuari. El control real queda desarmat després del desplegament; no s’activarà fins a completar les verificacions de seguretat i una prova supervisada.

    El paràmetre Shelly toggle_after pot retornar la sortida a OFF després d’un temps, però encara s’ha de comprovar en aquest dispositiu que el temporitzador persisteix i talla davant pèrdua de la Raspberry.

    Dades i exportació

    Fermentacions, lectures, esdeveniments i fotografies es desen al volum SQLite persistent de la Raspberry Pi.

    API i ChatGPT

    Hi ha una API autenticada de només lectura. Per consultar-la des de ChatGPT cal un connector o pont MCP configurat de manera privada.

    No exposis SQLite, la càmera ni el servidor directament a Internet.
