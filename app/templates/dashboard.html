    Control tèrmic

    La manta tèrmica és Shelly switch:0 segons confirmació de l’usuari. El codi de control real està preparat, però queda desarmat fins a verificar el relé/contactor, el tall tèrmic independent i l’estat segur després d’un reinici del Shelly.

    En mode real, el controlador renova un temporitzador local al Shelly perquè l’ordre ON caduqui a OFF si es perd la Raspberry.

    Dades i exportació

    Fermentacions, lectures, esdeveniments i fotografies es desen al volum SQLite persistent de la Raspberry Pi.

    Descarrega el ZIP des de l’actual o l’historial de fermentacions.

    API i ChatGPT

    Hi ha una API autenticada de només lectura. Per consultar-la des de ChatGPT cal un connector o pont MCP configurat de manera privada.

    No exposis SQLite, la càmera ni el servidor directament a Internet.

    Les dades s’actualitzen cada 30 segons mentre el seguiment és actiu · Emmagatzematge local SQLite · by gmuntal
